# h-level-product

按任务选择下列 Skill。每个入口可直接使用；不需要角色导航。

| Skill | 用途 |
| --- | --- |
| [human-writing](skills/human-writing/SKILL.md) | 编写、修订和审核自然、清晰的中文文稿，围绕读者任务组织有依据的事实、操作和结论。 |
| [release-management](skills/release-management/SKILL.md) | 从同一版本范围维护 changelog、站内发布说明和 GitHub Release，处理标签、资产、预发布、latest 与版本元数据的一致性。 |
| [spec-authoring](skills/spec-authoring/SKILL.md) | 使用可复用 PRD、TRD、API、ADR 和测试规格模板编写或维护正式规格，统一文档状态、功能路径与关联字段。适用于需要持久规格或指定模板的任务。 |
