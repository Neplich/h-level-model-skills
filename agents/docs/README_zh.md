# h-level-docs

按任务选择下列 Skill。每个入口可直接使用；不需要角色导航。

| Skill | 用途 |
| --- | --- |
| [docs-maintenance](skills/docs-maintenance/SKILL.md) | 维护带 change-map、frontmatter 和版本锚的文档集，按代码变更同步页面或审计事实、链接、导航及 public/internal 构建。 |
| [docs-site-bootstrap](skills/docs-site-bootstrap/SKILL.md) | 使用内置 VitePress 资产初始化或更新文档站，保留宿主内容并验证脚手架、导航和页面构建。 |
| [manual-gen](skills/manual-gen/SKILL.md) | 依据真实运行界面和代码编写图文操作手册，覆盖用户任务、步骤、结果与恢复方式。 |
