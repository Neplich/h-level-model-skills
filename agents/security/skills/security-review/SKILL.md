# 安全审查参考

明确审查范围后只读取相关检查表。宿主已有更完整的专用安全审查工具时，优先使用其验证工作流，本库参考按需补充缺少的审查面。

| 审查面 | 参考与主要产物 |
| --- | --- |
| 输入、执行与输出边界 | [AppSec](references/appsec.md)：可达 source-to-sink 路径 |
| 身份、资源与租户 | [授权](references/authorization.md)：预期与实现权限矩阵 |
| 解析依赖与供应链 | [依赖](references/dependencies.md)：版本、公告、可达性与升级路径 |
| 个人数据生命周期 | [隐私](references/privacy.md)：采集、接收方、保留与删除映射 |

发现包含位置、攻击前提或数据处理条件、已有防护、具体影响和修复方向。公告级别与本系统实际风险分别说明；无法验证的路径列明证据缺口。法律合规结论需另行核对适用地区的当前权威要求。

报告给出实际覆盖与限制。仅因普通功能涉及登录、依赖或个人数据，不自动扩展为整库审计。
